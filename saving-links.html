Saving Links to Grandview Exchange

For quick access to Grandview Exchange in your browser, you can create a bookmark (also called a favorite). This comprehensive guide explains how to create a bookmark or favorite to Grandview Exchange across various operating systems and web browsers.

Saving Bookmarks / Favorites in Your Browser

Save the link to Grandview Exchange in your browser to make it easy to get to the site without having to remember the link. In Google Chrome and Firefox, these saved links are called bookmarks. In Microsoft Edge, they are called favorites.

Create A Bookmark on Windows Computers

The steps for creating a bookmark on Windows depends on which browser you use. See below for steps for Google Chrome, Microsoft Edge, and Firefox.

Google Chrome

  1. Open Grandview Exchange in Google Chrome using this link: https://grandviewexchange.groups.io.
  2. Click the Star icon located at the far right end of the Address Bar.
  3. In the pop-up that appears, you can customize the following:
    • Name: Give the bookmark a short, recognizable title (e.g., "Grandview Exchange").
    • Folder: Select a folder to save the bookmark in. (Select "Bookmarks Bar" to keep the link permanently visible at the top of your Chrome browser window.)
  4. Click Done to save the bookmark.

Microsoft Edge

  1. Open Grandview Exchange in Microsoft Edge using this link: https://grandviewexchange.groups.io.
  2. Click the Star icon located at the far right end of the Address Bar.
  3. In the pop-up that appears, you can customize the following:
    • Name: Give the bookmark a short, recognizable title (e.g., "Grandview Exchange").
    • Folder: Select a folder to save the bookmark in. (Select "Favorites Bar" to keep the link permanently visible at the top of your Chrome browser window.)
  4. Click Done to save the bookmark.

Firefox

  1. Open Grandview Exchange in Microsoft Edge using this link: https://grandviewexchange.groups.io.
  2. Click the Star icon located at the far right end of the Address Bar.
  3. In the pop-up that appears, you can customize the following:
    • Name: Give the bookmark a short, recognizable title (e.g., "Grandview Exchange").
    • Location: Select a folder to save the bookmark in. (Select "Bookmarks Toolbar" to keep the link permanently visible at the top of your Firefox browser window.)
  4. Click Save to save the bookmark.

Create A Bookmark on Apple Computers

The steps for creating a bookmark on Apple Computers depends on which browser you use. See below for steps for Safari, Google Chrome, Microsoft Edge, and Firefox.

Safari

  1. Open Grandview Exchange in Safari using this link: https://grandviewexchange.groups.io.
  2. Click the Bookmark menu at the top of your computer's screen.
  3. Click the Add Bookmark menu item.
  4. In the pop-up that appears:
    • Add this page to: Name: Select Favorites.
    • Give the bookmark a short, recognizable title (e.g., "Grandview Exchange").
